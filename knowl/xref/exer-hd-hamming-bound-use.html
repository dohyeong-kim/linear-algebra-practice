연습문제 8. 해밍 상한의 사용.

  1. \([6,4,3]\) 선형부호가 존재하지 않음을 보이십시오. 이와 연습문제 3.1.7로부터, 길이 \(6\)이고 최소 거리가 \(3\)인 선형부호의 최대 차원은 \(3\)입니다.
    🔗
    🔗
  2. 길이 \(7\text{,}\) 최소 거리 \(3\)인 선형부호와 길이 \(10\text{,}\) 최소 거리 \(5\)인 선형부호의 차원이 모두 \(4\) 이하임을 보이십시오.
    🔗
    🔗
  3. \(d\le 2\)이면 해밍 상한이 아무 정보도 주지 않음을 설명하십시오.
    🔗
    🔗
  4. 정리 3.1.12의 증명을 고쳐, 선형이 아닌 부호 \(C\)에 대해서도 \(|C|\sum_{j=0}^{\lfloor(d-1)/2\rfloor}\binom nj\le 2^n\)이 성립함을 보이십시오.
    🔗
    🔗
🔗
예시답안.
  1. \(2^4\cdot 7=112>64\)입니다.
    🔗
    🔗
  2. \(2^k\cdot 8\le 2^7\)에서 \(k\le 4\)입니다. \(2^k(1+10+45)\le 2^{10}\)에서 \(2^k\le 1024/56<32\)이므로 \(k\le 4\)입니다.
    🔗
    🔗
  3. \(d\le 2\)이면 합은 \(\binom n0=1\)뿐이므로 부등식은 \(2^k\le 2^n\text{,}\) 즉 \(k\le n\)이 되어 자명합니다.
    🔗
    🔗
  4. 증명에서 선형성은 부호어의 수가 \(2^k\)라는 데에만 쓰였습니다. 공들이 서로소라는 논법은 임의의 부호에 대해 성립하므로 \(2^k\)를 \(|C|\)로 바꾸면 됩니다.
    🔗
    🔗
