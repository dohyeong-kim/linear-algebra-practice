연습문제 6. 행렬곱 지수의 하계.

정의 7.1.10의 \(C_{\mathbb F}(n)\)에 대해 다음을 보이십시오.
  1. \(C_{\mathbb F}(1)=1\)이고, 모든 \(n\ge 1\)에 대하여 \(C_{\mathbb F}(n)\ge n^2\)이다.
  2. 모든 \(n\ge 1\)에 대하여 \(C_{\mathbb F}(n)\le C_{\mathbb F}(n+1)\)이다.
  3. \(2\le\omega_{\mathbb F}\le 3\)이다.
예시답안.
  1. 각 출력 성분 \(c_{ik}=\sum_ja_{ij}b_{jk}\)는 상수가 아닙니다(\(A=0\)이면 \(0\)이고 \(A=E_{i1}\text{,}\) \(B=F_{1k}\)이면 \(1\)). 또한 어느 입력 성분과도 같지 않습니다. 예를 들어 \(a_{pq}=1\)이고 \(B=0\)이면 \(c_{ik}=0\)입니다. 따라서 각 \(c_{ik}\)는 어떤 연산의 결과여야 합니다. \(A=E_{i1}\text{,}\) \(B=F_{1k}\)이면 \(AB=G_{ik}\)이므로 서로 다른 출력 성분은 서로 다른 함수이고, 한 연산은 하나의 값만 만드므로 연산이 적어도 \(n^2\)번 필요합니다. \(n=1\)이면 곱셈 한 번으로 충분하므로 \(C_{\mathbb F}(1)=1\)입니다.
  2. \((n+1)\times(n+1)\) 행렬곱을 계산하는 알고리즘에서 마지막 행과 열의 입력 성분을 상수 \(0\)으로 바꾸면, 연산 횟수는 그대로이고 출력의 왼쪽 위 \(n\times n\) 블록이 \(n\times n\) 행렬의 곱이 됩니다.
  3. 상계는 본문에서 보였습니다. \(\tau\lt 2\)이고 모든 \(n\)에 대해 \(C_{\mathbb F}(n)\le cn^\tau\)라면 (a)에 의해 \(n^{2-\tau}\le c\)이므로 모순입니다. 따라서 \(\omega_{\mathbb F}\ge 2\)입니다.
