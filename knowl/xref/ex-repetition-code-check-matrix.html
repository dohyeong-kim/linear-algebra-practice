예시 3.1.10. 반복 부호의 검사 행렬.

반복 부호 \(R_n=\{00\cdots0,11\cdots1\}\)는 다음 검사 행렬을 가집니다.
\begin{align*} H=\begin{pmatrix} 1&1&0&\cdots&0\\ 0&1&1&\cdots&0\\ \vdots&&\ddots&\ddots&\vdots\\ 0&0&\cdots&1&1 \end{pmatrix}\in\mathbb F_2^{(n-1)\times n} \end{align*}
이 행렬의 각 행은 연속한 두 좌표가 같다는 조건을 나타냅니다. 따라서 \(Hx=0\)인 벡터는 모든 좌표가 같은 벡터이고, \(R_n=\{x\in\mathbb F_2^n:Hx=0\}\)입니다.
