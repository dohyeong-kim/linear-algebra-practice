정리 3.3.4. 해밍 부호의 매개변수.

\(r\ge 2\)일 때, \(r\times(2^r-1)\) 검사 행렬로 정의되는 이진 해밍 부호의 매개변수는
\begin{gather*} [2^r-1,2^r-r-1,3] \end{gather*}
이다.

증명.

검사 행렬 \(H\)는 \(2^r-1\)개의 열을 가지므로 부호의 길이는 \(2^r-1\)입니다. 또한 \(H\)의 열에는 \(\mathbb F_2^r\)의 표준기저가 모두 포함되어 있으므로 \(\operatorname{rank}(H)=r\)입니다. 따라서 계수-차원 정리에 의해
\begin{gather*} \dim\operatorname{ker}(H)=(2^r-1)-r=2^r-r-1 \end{gather*}
입니다.
이제 최소 거리를 구합시다. \(H\)에는 영벡터인 열이 없으므로 무게가 \(1\)인 벡터는 \(\operatorname{ker}(H)\)에 속하지 않습니다. 또한 \(H\)의 열들은 모두 서로 다르므로 두 열의 합은 영벡터가 아니며, 따라서 무게가 \(2\)인 벡터도 \(\operatorname{ker}(H)\)에 속하지 않습니다. 한편 서로 다른 두 열 \(u\)와 \(v\)를 택하면 \(u+v\)는 영벡터가 아니고 \(u\text{,}\) \(v\)와도 다르므로 \(H\)의 또 다른 열입니다. 이 세 열의 합은
\begin{gather*} u+v+(u+v)=0 \end{gather*}
이므로 이 세 열의 위치에서만 성분이 \(1\)인 무게 \(3\)의 부호어가 존재합니다. 따라서 최소 거리는 \(3\)입니다.
