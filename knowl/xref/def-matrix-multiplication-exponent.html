정의 7.1.10. 행렬곱 지수.

체 \(\mathbb F\)를 고정하자. 두 임의의 \(n\times n\) 행렬의 곱을 정확히 계산하는 데 필요한 최소 산술 연산 횟수를 \(C_{\mathbb F}(n)\)이라 하자. 여기서 알고리즘은 입력 성분과 체의 상수로부터 덧셈, 뺄셈, 곱셈을 수행하며, 각 연산의 비용은 \(1\)로 센다. 고정된 상수와의 곱셈도 이 횟수에 포함한다.
체 \(\mathbb F\) 위의 행렬곱 지수
행렬곱 지수:matrix multiplication exponent
는 다음과 같이 정의되는 실수 \(\omega_{\mathbb F}\)이다.
\begin{gather*} \omega_{\mathbb F}=\inf\bigl\{\tau\in\mathbb R_{\geq 0}: C_{\mathbb F}(n)=O(n^\tau)\bigr\}. \end{gather*}
여기서 점근적 상계의 상수는 \(\mathbb F\)와 \(\tau\)에 의존할 수 있지만 \(n\)에는 의존하지 않는다. 체가 문맥에서 명확하면 \(\omega\)로 쓴다.
