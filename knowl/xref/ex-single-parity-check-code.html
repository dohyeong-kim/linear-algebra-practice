예시 3.1.8. 단일 패리티 검사 부호.

단일 패리티 검사 부호 \(P_n=\{x\in\mathbb F_2^n:x_1+\cdots+x_n=0\}\) (\(n\ge 2\))은 영이 아닌 선형사상 \(x\mapsto\sum_{i=1}^n x_i\)의 커널이므로 차원이 \(n-1\)입니다. 무게가 \(1\)인 단어는 좌표의 합이 홀수이므로 \(P_n\)에 속하지 않지만, 무게가 \(2\)인 \(110\cdots0\)은 \(P_n\)에 속합니다. 따라서 \(P_n\)은 비율이 \((n-1)/n\)인 \([n,n-1,2]_2\) 부호입니다. 예를 들어 \(n=3\)이면 \(P_3=\{000,011,101,110\}\)이고, 이는 \([3,2,2]_2\) 부호입니다.
